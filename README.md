# Orbit has moved to Orbitive

Development of this workspace continues in
[Orbitive](https://github.com/iadev09/orbitive). This repository is retained as
read-only history and is archived.

New applications should depend on the `orbitive` facade. Reusable components
remain separately available as `orbit-*` packages from the Orbitive workspace.
The primitive runtime formerly published as `orbit-rs` now lives in
`orbit-core`.

- Repository: <https://github.com/iadev09/orbitive>
- Facade crate: <https://crates.io/crates/orbitive>
- Primitive crate: <https://crates.io/crates/orbit-core>
